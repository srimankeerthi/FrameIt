# 📸 FrameIt — Polaroid Image Editor

FrameIt is a lightweight web application for generating customizable Polaroid-style images. It provides real-time editing capabilities, allowing users to upload photos, apply filters, add captions, and export high-quality styled images directly from the browser.

## 🚀 Key Features

- Image upload with instant preview  
- Custom captions with selectable typography  
- Optional date labeling  
- Image adjustments:
  - Blur
  - Brightness
  - Contrast
  - Saturation
  - Grayscale  
- Preset styles:
  - Normal
  - Vintage
  - Black & White
  - Lomo  
- Frame customization:
  - Frame color
  - Background color
  - Shadow intensity
  - Tilt effect  
- Real-time preview updates  
- Export options:
  - Styled Polaroid (PNG)
  - Original image

## ⚙️ Architecture Overview

- FileReader API for client-side image loading  
- CSS filters for visual transformations  
- DOM manipulation for real-time UI updates  
- html2canvas for exporting styled output
